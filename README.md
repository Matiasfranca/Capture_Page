# Capture Page

## Visão geral
Este projeto é uma landing page estática para promover um workshop de marketing. A página foi construída com HTML e CSS puro, com foco em apresentar a proposta do evento, o formulário de inscrição e a descrição do palestrante.

## Objetivo
Conectar visitantes a uma página de inscrição atrativa, com visual forte, conteúdo organizado e design responsivo para diferentes tamanhos de tela.

## Estrutura do projeto

```text
Capture_Page/
├── index.html
├── LICENSE
├── css/
│   └── style.css
└── images/
    ├── arrow.jpg
    ├── face.jpg
    ├── ico.png
    └── people.jpg
```

## Arquivos principais

### index.html
Arquivo principal da página. Contém:
- Cabeçalho com título principal
- Seção de formulário para inscrição
- Área de apresentação do palestrante
- Estrutura semântica com `header`, `main`, `section` e `footer`

### css/style.css
Arquivo de estilização responsável por:
- Definir a aparência geral da página
- Criar o layout com fundo escuro e área principal destacada
- Estilizar o formulário de inscrição
- Ajustar a responsividade para telas menores

## Recursos visuais
A pasta de imagens contém os seguintes ativos:
- `images/ico.png` — ícone da página
- `images/people.jpg` — imagem de fundo da área principal
- `images/face.jpg` — foto do palestrante
- `images/arrow.jpg` — ícone usado no seletor de cidade

## Conteúdo apresentado na página
- Título principal: "PARTICIPE DO WORKSHOP QUE VAI MUDAR O SEU NEGÓCIO"
- Texto de incentivo para inscrição
- Formulário com campos para nome, email e seleção de cidade
- Botão de inscrição
- Apresentação do palestrante Carlos Fontana

## Características
- Página simples e estática
- Estilo visual moderno e chamativo
- Formulário de cadastro integrado visualmente ao layout
- Design responsivo para telas menores

## Como visualizar
Abra o arquivo [index.html](index.html) em um navegador para ver a página.
